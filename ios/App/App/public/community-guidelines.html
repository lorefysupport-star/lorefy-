المحتوى الممنوع

  • التحرش أو التهديد أو خطاب الكراهية أو التنمر.
  • المحتوى الجنسي الصريح أو استغلال القاصرين أو الترويج للعنف.
  • نشر المعلومات الشخصية أو انتحال الهوية.
  • الرسائل المزعجة والتلاعب بالتقييمات والروابط الخادعة.
  • نشر نصوص أو صور تنتهك حقوق أصحابها.

الحرق

استخدم علامة الحرق عندما تذكر أحداثاً مهمة، ولا تضع الحرق في اسم المستخدم أو بداية المراجعة أو الصور الظاهرة للعامة.

الإبلاغ والحظر

يمكنك الإبلاغ من قائمة أي مراجعة أو تعليق واختيار السبب. استخدم الكتم لإخفاء محتوى مستخدم، أو الحظر لإخفائه ومنع التفاعل. البلاغ لا يعني الإدانة تلقائياً؛ يراجعه فريق Lorefy ويتخذ الإجراء المناسب.

الإجراءات

قد نزيل المحتوى أو نقيده، وننبه الحساب أو نوقفه مؤقتاً أو نهائياً بحسب شدة المخالفة وتكرارها. المخاطر المباشرة أو المحتوى غير القانوني يعالج بأولوية.

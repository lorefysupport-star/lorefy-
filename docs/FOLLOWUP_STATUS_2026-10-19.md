## خلاصة جلسة الاستكمال

تربط كل مشكلة بالسبب والاختبار وحدود المصدر؛ لا إغلاق لاختبارات الجهاز والخدمة.

- LF-080: مهلة تحميل ملف الكتالوج وإعادة المحاولة المعزولة (`b6d986f`).
- LF-081: اختيار كتالوج الرواية/الكوميكس وفق التصنيف المشترك (`ed2ea33`).
- LF-082: قراءة JSON لا تبقى معلقة بلا نهاية (`db313d8`).
- LF-083: فشل اكتشاف المصدر لا يبقى محفوظًا طوال الجلسة (`e03ba4e`).
- LF-084: توحيد طلب بحث الاسم الجاري مع بقاء سياق كل محرر مستقل؛ سجل Git لهذا التحديث.

التحقق هنا اختبارات المصدر والنسخ المتطابقة، وليس قياس سلاسة الجوال أو اكتمال
كل مزوّد حي. تفاصيل ما بقي غير مثبت محفوظة أدناه.

## جلسة الاستكمال: ملفات الشخصيات

أو تجاوز active.7 حالات جديدة و106 مرتبطة و2315 كاملة ناجحة. المهلة والتحقق
من الرد والاستعادة بعد الفشل باقية؛ لا تغيير للمفضلة أو خدمة أو بيلد.

LF-083 يزيل فشل اكتشاف مصدر الشخصيات من الكاش كي تنجح المحاولة بعد رجوع الاتصال.
9 حالات جديدة و2308 كاملة ناجحة؛ الطلب الجاري والنجاح مشتركان، دون تغيير قواعد المطابقة.

LF-082 يحد قراءة محتوى ردود الشخصيات والصور، كي لا يعطل مزوّد متوقف كل النتائج.
13 حالة جديدة و2299 كاملة ناجحة؛ القوائم والبدائل وحالة الاكتمال محفوظة.
المهل لكل مرحلة وليست وعدًا بزمن شامل أو بإلغاء الاتصال؛ لا بيلد أو خدمة.

LF-081 يطابق كتالوج الشخصيات مع تصنيف الروايات والكوميكس في اللغتين، ويتجاوز
تحميل كتالوج لكتاب عادي مستثنى.10 حالات جديدة و2286 كاملة ناجحة؛ لا تعديل لسجلات الأعمال.

LF-080 يضيف مهلة لملف الكتالوج المحلي، ويحرر المحاولة الفاشلة ويحمي المحاولة
الجديدة من callbacks قديمة.8 حالات جديدة و2276 كاملة ناجحة؛ لا تغيير للأعمال
أو التقييمات أو أصول الإطارات. فحص الجهاز والخدمة يبقى مستقلاً.

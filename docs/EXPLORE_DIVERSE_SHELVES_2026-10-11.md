# Explore and friend rating layout — 2026-10-11

The friend rating row now reserves an independent 32px numeric badge. Five feather slots have explicit compact dimensions that override the older design-system minimum sizes; quarter ratings keep their original clipped fill. The change does not modify ratings or reader state.

Explore previously ranked only the currently loaded shard. Several formats had no discovery-approved launch records, while most approved Arabic novels/books belonged to one writer. A 237KB local bibliographic selection now supplies 278 actual works across all eight formats, before loading the next relevant catalog shard. This is a bounded starting selection alongside the full searchable catalog, not a replacement for that catalog.

Themed collections cover comics, Arabic/world novels, science, philosophy, history, travel, light novels, web novels, manga, manhwa and manhua. Each visible shelf limits a writer to one work. Shared identity aliases remove repeated works across shelves and exclude library works under their canonical ID. Author bibliographies stay on author pages. Small residual one-writer shelves are suppressed. Existing account preferences still order candidates within each themed collection and the personal/genre shelves.

`uploads/lorefy-editorial-picks.js` contains the bounded launch records and exact-ID enrichment. `docs/explore-verification/editorial-sources.json` records each title, writer, source and review basis. Primary sources include publisher records from Hindawi/Safahat, Penguin, Scholastic, DC, Marvel, Abrams and author sites; Royal Road authors’ own fiction pages; and exact AniList/MAL IDs for light-novel author/content metadata. Existing MangaDex and other provider content classifications are retained for the illustrated Asian formats. New nonfiction and fiction entries are metadata only: no imported book or chapter text. Source artwork remains linked with the app’s existing legal fallback behavior.

Content screening for the specific publisher/author selections is an editorial inference from metadata, not a formal age classification or full-text audit. Unknown unrelated records remain ineligible. Explicit and declared AI flags are checked before enrichment and still block discovery. Royal Road entries carrying a sexual-content warning were omitted from this new selection. Source ratings are displayed only when attributed; no ratings, popularity or activity were synthesized. Newly added bibliographic records have no invented page/chapter totals or publication dates.

The initial page, on-demand source ingestion, compact catalog builder and full catalog worker share the same selection. A full worker replacement retains the new launch records. Native generated assets were copied from the final source, with no signed build upload, database mutation, reseed or dependency upgrade.

Verification artifacts in `docs/explore-verification/` record the test suite, real-browser type switching, canonical/unsafe record behavior, responsive rating measurements and screenshots. Browser checks use the local demo only. The existing signed Build 34 IPA and frozen project archive remain unchanged. These source changes require a new native build to reach existing TestFlight installs.

# Lorefy App Store Metadata Worksheet

Complete these fields in App Store Connect after the final build is tested. Do not submit placeholder text.

| Field | Release value |
| --- | --- |
| App name (30 characters max) | Lorefy |
| Subtitle (30 characters max) | Track stories you love |
| Primary category | Books |
| Secondary category | Entertainment |
| Support URL | Production HTTPS support URL |
| Privacy policy URL | Production HTTPS privacy-policy URL |
| Marketing URL | Optional production HTTPS landing page |
| Review notes | Login route, review account, and key test flows |

## Screenshots

Capture only the released iPhone build. Include real catalogue browsing, a work detail page, reading progress, profile/lists, and settings/account deletion. Do not include copyrighted promotional imagery unless the redistribution licence permits App Store marketing use.

## Beta review notes template

Explain any sign-in requirement, provide a working review account or a review-only mode, list the exact navigation to delete an account, and identify content-reporting and blocking controls if community content is enabled.

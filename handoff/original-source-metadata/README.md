# Lorefy Clean App

هذه نسخة مرتبة ومتكاملة من تطبيق Lorefy، جاهزة للتشغيل المحلي أو الرفع كواجهة ويب تقدمية.

## التشغيل المحلي

افتح PowerShell داخل هذا المجلد وشغّل:

```powershell
node tools/lorefy-api-server.js 8793
```

ثم افتح:

```text
http://127.0.0.1:8793/index.html?fresh=full-audit-v2
```

استخدم خادم Lorefy المرفق بدل خادم ملفات عادي؛ فهو يشغّل أيضًا بوابة الكتالوج والصور المطلوبة من المصادر الخارجية.

## محتويات الحزمة

- `index.html`: نقطة تشغيل التطبيق.
- `styles/`: نظام التصميم والوضعين الفاتح والليلي.
- `modules/`: أنظمة الكتالوج والشخصيات والأغلفة والمشاركة والتحديثات.
- `uploads/`: بيانات الأعمال وخريطة التحميل المرحلي.
- `backend/`, `auth/`, `config/`, `monitoring/`: الربط والإعدادات والمراقبة المحلية.
- `vendor/`: مكتبات التشغيل المثبتة محليًا.
- `tools/lorefy-api-server.js`: الخادم المحلي وبوابة مصادر الكتالوج والصور.
- `launch/`, `manifest.webmanifest`, `sw.js`: ملفات PWA والأيقونات والعمل دون اتصال.

## الفحص

لتشغيل اختبارات المشروع:

```powershell
node --test tests/*.test.js
```

الحسابات السحابية والدفع الحقيقي يحتاجان إعداد Supabase ومفاتيح المتاجر قبل الإطلاق.

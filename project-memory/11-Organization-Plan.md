# تنظيم دون كسر المشروع

## ترتيب القراءة الحالي

[[00-Home]] ثم [[13-Project-Story]] ثم [[14-Feature-Coverage]]، وبعدها
[[08-Feature-Router]] وملاحظة النظام و[[09-Data-Contracts]].
[PROJECT_MAP](../PROJECT_MAP.md) هو مدخل جذر المشروع، و[[12-Device-Repairs]]
لوحة الحالات. [[sessions/2026-10-15-Source-Reorganization]] يسجل آخر دمج.

التنظيم المعتمد فصل المعرفة والمسؤوليات لا إعادة توزيع ملفات runtime.
لم ننقل الملف الرئيسي أو نعيد تسمية globals أو مفاتيح البيانات، ولم نحذف
النسخ المولدة أو الأصول. سجل الجلسة يحفظ القرارات التاريخية؛ ملاحظات الأنظمة
تحفظ العقد الحالي؛ الفهرس المولد يحفظ البصمات فقط. لا تنسخ سجلًا تاريخيًا
كحالة حالية، ولا تستبدل معرفة يدوية بملخص آلي عام.

## الطبقات

| الطبقة | المكان | التصرف الصحيح |
| --- | --- | --- |
| المصدر الفعلي | الجذر، `modules/`, `styles/`, `auth/`, `backend/`, `uploads/files/lorefy-app.js` | تعديل محدود واختبارات؛ لا نقل جماعي للكود لأجل التنظيم |
| البيانات والأصول | `uploads/`, `output/api-catalog/`, `launch/`, `design-source/` | ليست ملفات زائدة؛ لا تحذفها لأن حجمها كبير أو لها نسخ مشتقة |
| أدوات التحقق | `tools/`, `tests/`, `qa/`, `docs/` | افصل الدليل التاريخي عن نتائج التشغيل الجديد |
| النسخ المولدة | `ios-web/`, `ios/App/App/public/` | المصدر أولًا ثم تحضير/نسخ عند تغيير runtime فقط |
| الدليل المجمد | `archives/`, `build34/`, `handoff/` | احفظه؛ ليس مصدر تغيير يومي ولا تعليمات نشر |
| معرفة المشروع | `project-memory/` | تنظيم وروابط وعقود وتواريخ، خارج تطبيق المستخدم |

## ما تم تنظيمه داخل الذاكرة

- صفحات بدء قليلة، خرائط أنظمة، قرارات، وصفات فحص، سجل جلسات، قوالب وصندوق مراجعة.
- الفهرس المولد في `generated/` منفصل عن الملاحظات اليدوية.
- البحث المحلي يفضّل معرفة الأنظمة على سرد أسماء الملفات، ويجلب روابط مجاورة محدودة.
- `memory:audit` يكشف الملاحظات غير المرتبطة والتكرار المطابق دون حذف تلقائي.

## لا تنظيف تلقائي خطِر

لا تحذف ملفات أو اعتماديات أو بيانات كتالوج، ولا تعيد تسمية مفاتيح التخزين،
ولا تُشغّل كل أدوات patch/import. بعض الأدوات تغير مصادر أو بيانات كبيرة.
أي تنظيف للكود الفعلي يحتاج نطاقًا مستقلًا ومبررًا واختبارًا قبل/بعد.

الفهرسة تحفظ المسارات والأحجام والبصمات فقط ضمن قائمة مسموحة؛ لا تنسخ
محتوى المصدر أو سجلات المستخدمين أو الأسرار. معرفة كل ملف مدرج ليست ضمنية.

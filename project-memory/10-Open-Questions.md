# أمور لا تُغلق بالافتراض

هذه قائمة من أدلة المصدر المؤرخة، وليست فحصًا مباشرًا للحسابات أو الخدمات.
لا تغيّر الأسرار أو قاعدة البيانات ولا تصدر بناءً جديدًا بسبب هذه القائمة.

| الأولوية | ما يحتاج تحققًا | الدليل المؤرخ | شرط الإغلاق |
| --- | --- | --- | --- |
| قبل الاعتماد على push | تسليم APNs خارج التطبيق | [تقرير 13 أكتوبر](../docs/NOTIFICATIONS_VERIFICATION_2026-10-13.md) سجّل `server_not_configured` | إعداد مصرح به + قبول APNs + وصول فعلي على iPhone؛ ليست نتيجة محلية حالية |
| قبل الإصدار العام | حقوق المحتوى ومراجعة الخصوصية | [حقوق المحتوى](../docs/CONTENT_RIGHTS_AUDIT.md)، [فجوات Build 34](../docs/BUILD34_KNOWN_GAPS.md) | أدلة مراجعة واعتماد مالك؛ نجاح UI لا يغلقها |
| قبل الاعتماد على الحفظ | force-quit/offline وحساب ثان | [إصلاح استرجاع الحالة](../docs/STATE_RECOVERY_FIX_2026-10-03.md) | اختبار حسابين مخصصين وأجهزة حقيقية دون بيانات مستخدمين فعليين |
| قبل تعديل اللستات العامة | وضع RPC/migration الفعلي | [تقرير 11 أكتوبر](../docs/FEATURE_AUDIT_20261011.md) | فحص قراءة مصرح به للعقد المنشور، لا إعادة تشغيل migration تلقائيًا |
| قبل ادعاء سلاسة iPhone | scrolling/memory/cold launch | [تحديث 14 أكتوبر](../docs/APP_UPDATE_2026-10-14.md) | قياسات جهاز حقيقي وإجراءات قابلة للتكرار |
| قبل عمل بيع حقيقي | الحالة التجارية الحالية للحزم | [[decisions/Temporary-Free-Bundles]]، [ملف الحزم](../docs/PAID_COLLECTIONS_2026-10-11.md) | إعادة فحص العقد المحلي والخادم حسب طلب المستخدم؛ لا تفعّل تحصيلًا |
| قبل تغيير الاعتماديات | انطباق تحذيرات قديمة على المصدر الحالي | [الفجوات التاريخية](../docs/BUILD34_KNOWN_GAPS.md) و[[04-Current-State]] | فحص جديد للنسخ والمسارات المتأثرة؛ لا تعتمد على نسخة Build 34 القديمة |

عند وجود دليل جديد: حدّث الصف مع التاريخ، الأمر/الخطوات، النتيجة وحدودها،
واربط سجل الجلسة. احتفظ بالدليل القديم بوصفه تاريخيًا، لا تحذفه.

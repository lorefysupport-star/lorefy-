# Ponytail: إخفاء شريط بيانات العمل الفارغ

طلب المالك السكيل التالية من القائمة. اختير Ponytail رقم2 لتطبيق أصغر إصلاح كامل على فراغ شريط البيانات في تفاصيل العمل، مع بقاء قرار إبقاء النبذات وحذف رابط مصدرها.

## التشخيص والإصلاح

ظهر شريط `.lf-work-facts` في «الحرافيش» بلا نص أو عناصر أبناء، لكنه حجز26px وحدّين بصريين. فشل اختبار المتصفح قبل الإصلاح لأن ارتفاعه26بدل0. الفحص شمل المكوّن المنتج له في modules/lorefy-review-editor.js، والمستهلك الذي يقرأ textContent في modules/lorefy-chapter-detail.js.

قاعدة CSS واحدة في [work experience](../../styles/lorefy-work-experience.css): `.lf-work-facts:empty` يغيّر display إلىnone داخل نطاق تفاصيل العمل. عنصرDOM باقٍ لقارئ metadata، وتظهر البيانات تلقائيًا إذا أضيفت لاحقًا. لا شرط React أو مستمع جديد، ولا تعديل لملف JavaScript أو نص أو سجل كتالوج.

نسخة CSS فقط في index/SW صارت `20261021-empty-facts-v1`، وcache `lorefy-v549-empty-facts`. نُسخت CSS وindex وSW إلى نسختي الويب المولّدتين؛ نسخة app.js بقيت reader-filter-polish السابقة.

## الأدلة

- 33اختبارًا مرتبطًا ناجحة، تشمل تفاصيل العمل واستهلاك metadata والفصول وملفات الحزمة.
- 8حالات متصفح: الحرافيش وBerserk × AR/dark/320 وAR/light/390 وEN/dark/1024 وEN/light/768. أربع حالات فارغة ارتفاعها0، وأربع مليئة ظاهرة بنصها السابق.
- على سياق المتصفح المعزول أضيف عنصر QA metadata مؤقتًا داخل الشريط الفارغ، فظهر تلقائيًا، ثم أزيل فاختفى؛ لا كتابة بيانات أو snapshot أثناء العنصر الاختباري.
- نصوص النبذات مطابقة حرفيًا للجولة السابقة ولا روابط مصدر في قسم القصة. المحفوظ الشخصي مطابق قبل/بعد. تنقل القصة→المراجعات بالأسهم وHome محفوظ، ومؤشر الفلاتر نشط واحد.
- الفحص الكامل النهائي:2345اختبارًا،0إخفاقات؛ full-tests.log.
- الأدلة المحلية خارج المستودع في outputs/lorefy-ponytail-empty-facts بمجلد الشات: before.json وصور قبل/بعد وbrowser-verification.json وسجلات الاختبارات.

العمل محلي فقط، دون بناء أو نشر. لم تُفحص iOS الفعلي أوVoiceOver؛ لا ادعاء بتصحيح دقة بيانات الفصول أو حالة أي عمل. [[systems/Explore-Works]] | [[10-Open-Questions]] | [[14-Feature-Coverage]]

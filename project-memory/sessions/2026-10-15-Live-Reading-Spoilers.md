# تحديث تقدم القراءة وحماية الحرق

طلب المستخدم: إكمال الإصلاحات مع بقاء بث الآيفون مفتوحًا. الأساس `542b39c`
مع الإصلاحات المحلية السابقة، دون دفع أو تثبيت أو إصدار جديد.

## أسباب مثبتة وإصلاحها

- `canReveal` اختبر الحقل الحالي وlegacy معًا؛ لذا سمح `ch:12` أو `vol:4`
  بفتح الحرق رغم `chapter:0` أو `volume:0`. قارئ الموضع الموحد `progressAt`
  يعطي الأولوية للحقل الحالي، ويدعم legacy عند غيابه والتقدم الرقمي القديم،
  ويرفض القيم غير المنتهية. نمو `Infinity` لا يدخل أحداث التقدم. عقد إكمال
  العمل والإظهار اليدوي للحرق لم يتغيرا.
- محرر الملاحظة كان يعيد الفصل أو المجلد القديم عند الصفر، ويختار فصلًا بدل
  الصفحة الفعلية. يستخدم الآن نفس قارئ الموضع في التهيئة وتغيير الوحدة والعمل.
- قسم الفصول لم يحدّث العداد عند وصول `lorefy:stored-state`. يحدث الآن الملخص
  والعلامات والأزرار في مكانها دون إعادة إنشاء محرر التعليق. زر المتابعة يقرأ
  أحدث checkpoint عند الضغط، ويختفي عند بلوغ الإجمالي ويعود عند خفض التقدم.
- أثناء الفحص ثبت سبب فقد المسودة: قراءة نص أول ستة أبناء لصفحة العمل التقطت
  «6 فصل مقروء» كإجمالي 6 بدل إجمالي العمل 384، فأعادت بناء القسم. الإجمالي
  يقرأ الآن `.lf-work-facts` المخصصة لبيانات العمل، ثم المصادر المعروفة؛ لا
  يستخلص عدد الفصول من سجل المستخدم أو أزرار القراءة.

## الأدلة

المصادر: [chapter UI](../../modules/lorefy-chapter-detail.js)،
[diary core](../../modules/lorefy-reading-diary-core.js)،
[diary UI](../../modules/lorefy-reading-diary.js)،
[chapter CSS](../../styles/lorefy-chapter-detail.css).

قبل الإصلاح: أربعة اختبارات للحرق والموضع فشلت، واختبار مستقل أثبت إجمالي 6
الخاطئ. المتصفح أكد عدم تحديث العداد، كشف الحرق، وملء الفصل/المجلد القديمين.
بعد الإصلاح: 57 اختبارًا موجهًا ناجحًا، و14 حالة متصفح بالعربية والإنجليزية
دون أخطاء صفحة: تحديث العداد وعلامات القراءة، بقاء نفس DOM node ونص مسودة
التعليق، بلوغ الإجمالي ثم خفضه، متابعة الفصل 7 بعد checkpoint 6، حجب الحرق
والإظهار/الإخفاء اليدوي، واختيار الصفحة 7 بدل الفصل/المجلد القديمين.

المجموعة الكاملة بعد مزامنة الأصول: **1186/1186 نجاحًا، صفر فشل**. الذاكرة
المحلية حديثة وفحصها خالٍ من المشاكل، وستة ملفات runtime متطابقة SHA256 في
المصدر ونسختي الويب الأصليتين.

الإيصالات في `verification/reading-live-spoiler-20261015` بمجلد التسليم خارج
التطبيق. QA معزول في demo وطلبات Supabase محجوبة. ملفات المصدر والكاش ونسختا
الويب الأصليتان زومنت؛ بث الهاتف يعرض التطبيق المثبت السابق ولا يثبت تثبيت
الإصلاحات. لا صور حسابات أو مفاتيح داخل الخزنة. الشراء وAPNs مستقلان.

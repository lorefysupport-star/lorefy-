# تطبيق السكيلز: استعادة كاش الشخصيات وتنقل المحرر

النطاق الذي وافق عليه المالك: بدء تدقيق Ponytail وImpeccable وتوثيق تدفق
بحث الشخصيات، في النسخة المعزولة المجلوبة من GitHub. التحديث أعلاه هو
الأساس؛ الإصلاحان تغييرات محلية غير مرفوعة. لا بناء أصلي أو تغيير خدمة.

## ما تغير ولماذا

- `readCache` في [نظام الشخصيات](../../modules/lorefy-character-system.js)
  يرفض جذرًا أو cast غير صالح، ومدخلات null/primitive/array داخل cast.
  سابقًا كان JSON صحيح البنية العامة لكن غير صالح للعقد يوقف البحث قبل
  المزوّد (`cast.some`/`concat`)، أو يفقد إصلاح الكاش عند حفظ جذر مصفوفة.
  تُترك مدخلات الأعمال الصحيحة والمفضلة محفوظة؛ التحقق لا يمس خدمة حية.
- [محرر الشخصيات](../../modules/lorefy-growth-features.js) يضيف محطة Tab
  واحدة لتبويبي طريقة البحث وLeft/Right/Home/End مع استعادة تركيز التبويب
  بعد التفعيل، وبقاء سلوك المسح واختيار النمط نفسه. الشكل والأصول محفوظة.
- حُدثت نسختا asset URL في index وservice worker، ونسخت الملفات الأربعة
  المتأثرة فقط إلى ios-web وios/App/App/public وقورنت بايتًا ببايت.

## دليل جديد

- كاش: سبع حالات جديدة، ست منها فشلت قبل الإصلاح. تشمل جذر string/array،
  cast string/object، شخصية null، مدخل null، والحفاظ على عمل صحيح مجاور.
- لوحة المفاتيح: حالتان AR/EN فشلتا قبل الإصلاح ونجحتا بعده. الفحص
  المرتبط النهائي:85 ناجحة. اختبارات مفاتيح الأصول وترتيب التحميل:34 ناجحة.
- `npm test`:2324 ناجحة، صفر فشل/تخطٍّ/إلغاء، exit0 في20 أكتوبر.
  الإعادة النهائية جاءت بعد تحديث تأكيدَي نسخ الأصول إلى revision الجديد؛
  الجولة الأولى كشفت تأكيدين متعلقين بالـrevision القديم.
- متصفح Chromium حقيقي: ست حالات AR/dark وEN/light عند320/390/440px؛
  الأسهم وHome/End وTab والمسح وEscape ورجوع التركيز، مع حفظ المفضلة.
  لا overflow أفقي بالمحرر ولا pageerror. عرض320 فُحص مع reduced motion.
- Impeccable detect4.3.1: صفر نتائج آلية في الملفات الثلاثة المحددة؛
  لا يُعد هذا حكم وصول شاملًا. الخلل السلوكي كُشف بالتشغيل اليدوي.
- Diagram Design أنتج مخطط HTML/SVG مستقلًا باستخدام ألوان وخط لورفاي؛
  self_check نجح، والمخطط راجع مسار الطلب المشترك وactive لكل مستدعٍ.

الأدلة والمخطط والتقرير في مجلد outputs/lorefy-skills-application الموازي
لهذا checkout، خارج حزم التطبيق. لا بيانات حسابات حقيقية في الأدلة.

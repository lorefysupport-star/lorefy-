# استكمال إصلاح معرض تقييمات الشخصيات

## الطلب والسبب

طلب المالك متابعة إصلاح المشكلات، مع بقاء منع البيلد والرفع إلى Apple.
المصدر قبل التعديل يلتقط entries مرة واحدة، ويخرج مبكرًا إن لم تُحل أي
شخصية. كما أن catch في hydrator يخزن [] كأن الفشل نتيجة فارغة مؤكدة.

## التغيير المحدد

- فتح المعرض يبني أدواته مرة واحدة ويقرأ البيانات الجديدة عند وصول cast.
- تحديث البيانات يحتفظ بعنصر البحث ووضع التجميع وحد العرض، وبصمة المحتوى
  تمنع إعادة رسم البطاقات بلا تغيير. استُخدمت دورة الصيانة القائمة، لا timer جديد.
- صفر تقييمات ونتيجة cast فارغة حقيقية ليسا تحميلًا أبديًا.
- الفشل لا يدخل كاش النجاح، ويظهر Retry. لا تعاد الشبكة مع كل tick؛ إعادة
  المحاولة صريحة، والطلبات الجارية موحدة حسب العمل. أخطاء provider المتزامنة محتواة.
- الاستجابة تقرأ تقييمات المالك الحالي؛ النافذة السابقة تغلق عند تبديل الحساب
  ولا تُرسم بعد إغلاقها. callbacks المالك السابق لا تنفذ في الحساب اللاحق.
- تحديث كاش المصدر إلى `20261015-gallery-hydration-v1` وservice worker
  `lorefy-v459-gallery-hydration`، ونسخ الملفات الثلاثة المتأثرة فقط إلى نسختي الويب.

# بحث Obsidian وتطبيقه على ذاكرة Lorefy

## الطلب والحدود

بحث أفضل استغلال للبرنامج وتطبيق النتائج. تغييرات الذاكرة وأداة تدقيقها
واختباراتها فقط؛ لا تغيير في تطبيق المستخدم أو بياناته أو إنشاء build.
تعديلات إعدادات Build 35 السابقة محفوظة وليست ضمن هذا العمل.

## البحث والقرار

المصادر الرسمية والبدائل وسبب الاختيار في [[16-Obsidian-Workflow]].
البداية المحلية: Bases وProperties وTemplates مفعّلة بالفعل، دون إضافات
مجتمع. CLI الرسمي كان معطلًا ثم فعّله المالك. أمر `vault` أكد المسار
الصحيح، والنسخة 1.14.4 مع installer 1.14.4. لا تثبيت إضافات أو مزامنة
أو نشر للخزنة؛ أمر plugins:restrict أعاد on وقائمة إضافات المجتمع فارغة.

## ما طُبق

- [[15-Work-Control]] وثلاثة عروض Bases محلية للعمل والمعرفة والجلسات.
- ثلاث فجوات متابعة مرتبطة بأدلتها دون إعادة نسخ تقرير الجهاز كاملًا.
- خصائص وقوالب تبدأ دون تحقق، وتفصل المصدر عن الجهاز والخدمة وتاريخ المراجعة.
- حماية رابط Bases/Canvas داخل الخزنة وتوسيع اختبارات التدقيق.
- ربط الصفحة الرئيسية والخريطة والوكيل ودليل صيانة الذاكرة.

## التحقق

قبل التنفيذ: فشلت الحالات الخمس الجديدة كما هو متوقع؛ عدم وجود اللوحات
والبنود، قوالب بلا حقول منظمة، وعدم دعم روابط Bases/Canvas في المدقق.
بعد التنفيذ نجحت 22 حالة في اختبارات الذاكرة والتدفق، exit 0.

استعلامات CLI الأصلية، من مسار الخزنة، تحققت من:

- Work: ثلاثة بنود؛ تحقق الجوال يعرض اثنين، والخدمة بندًا واحدًا.
- Knowledge: 18 نظامًا وقرارًا وبندًا؛ عرض المراجعة يعرض 15 ملاحظة دون
  reviewed_on، ولا يضع تواريخ حديثة تلقائيًا. البنود الثلاثة المراجعة اليوم
  ليست ضمن هذا العرض، لكنها موجودة في عرض المعرفة الكامل.
- Sessions: 12 جلسة؛ أثناء التنفيذ جلسة واحدة in-progress.
- قراءة workspace عبر CLI أكدت فتح `15-Work-Control.md`.

لا تُسجل لقطة النافذة كدليل بصري نهائي: أظهرت الصورة صفحة 13 السابقة رغم
تأكيد workspace فتح صفحة 15. قراءة DOM عبر CLI أكدت عنوان اللوحة وصفوف
العمل الثلاثة في الصفحة الفعلية؛ دليل البيانات استعلام المحرك الحقيقي.

اختبار إضافي كشف أن قارئ JSON وحده يرفض YAML الذي قد يحفظه محرر Obsidian.
أضيف `yaml@2.9.1` كاعتماد تطوير مقفل، مع `npm install --ignore-scripts
--no-audit --no-fund` دون lifecycle scripts أو native sync. يقبل اختبار
اللوحات والخصائص الصيغتين ويحافظ على booleans وnull؛ لا يفرض تنسيقًا خاصًا
يمنع تحريرها من واجهة البرنامج.

## إيصال الجولة النهائي

على أساس `1950599` مع التغييرات المحلية لهذه الجولة في الذاكرة وأداتها
واختباراتها واعتماد YAML التطويري، مع حفظ إعدادات البناء السابقة:

- `node --test tests/project-memory.test.js tests/project-memory-workflow.test.js`:
  exit 0، 23 نجاحًا، صفر فشل؛ منها ست حالات جديدة فشلت قبل التنفيذ ثم نجحت.
- `npm test`: exit 0؛ 1204 نجاحات، صفر فشل أو تجاوز أو إلغاء.
  الدليل المحلي خارج Git: `artifacts/lorefy-obsidian-research-final-tests.log`
  في مجلد المحادثة. لا يُستعاض بهذا عن تحقق جهاز أو خدمة حية.
- `memory:refresh` ثم `memory:audit`: 65 ملاحظة و498 ملف مصدر، بصمة حديثة،
  بلا روابط معطوبة أو ملاحظات يتيمة أو مجموعات تكرار مطابق.
- بحث `memory:search -- لوحة التطوير` أعاد `15-Work-Control.md` أولًا.
- أوامر Bases الأصلية وDOM تحققت من البيانات والصفحة؛ اللقطة المذكورة أعلاه
  ليست دليلًا نهائيًا على كل العرض البصري أو تفاعل اللمس.
- `git diff --check`: exit 0؛ لا تعارضات دمج متبقية.

لا تغيير في runtime التطبيق أو قاعدة البيانات أو الأسرار أو حزم الإطارات،
ولا إنشاء binary أو رفع إلى Apple. رفع المصدر المصرح به منفصل عن النشر.
بعد commit التوثيق تُجدّد البصمة المحلية لتطابق HEAD دون إعادة ختم الملاحظات.

## الحدود

اختبار بنية JSON/YAML للوحة ليس فحص عرضها داخل Obsidian. لا تدريب نموذج،
لا قراءة دلالية تلقائية لكل المصدر، ولا مزامنة لكل تغيير من دون مراجعة.
تاريخ المراجعة في بنود المتابعة يخص قراءة الدليل القديم، لا إعادة تنفيذ
اختبار جهاز أو خدمة. [[10-Open-Questions]] يبقى مرجع الحدود الحية.

# تحديث GitHub مع حفظ الإصلاحات المحلية

طلب المستخدم جلب آخر تحديث من GitHub لنكمل منه. جُلب `main` عند
`542b39cef11d5d6bd07ce324ab7288d77869fd10`؛ قاعدة المصدر المحلية المؤكدة
سابقًا كانت `47638621057a3759e14ea98dd7076f47b601d1b5`.

حُفظ المصدر الحالي كاملًا قبل الدمج في أرشيف للقراءة فقط، وإيصال المقارنة
والاختبارات في مجلد التحقق المحلي `verification/git-update-20261015`
بجذر مساحة العمل خارج جذر التطبيق. لم يُستخدم reset ولم تُحذف ملفات المصدر.

## قرار الدمج

- تُحفظ إصلاحات المزامنة عند تطابق النسختين، وعدم إعادة كتابة تعديل بعيد
  بقيمة محلية قديمة، مع الحماية من تبديل الحساب أثناء الطلب.
- تُحفظ دقة أرباع النجوم والتحديث المباشر بعد الاستيراد، والتصدير عبر
  Filesystem/Share وحقول CSV الحالية والقديمة، وتحسين محرر المنشور.
- تُحفظ الترقية إلى Capacitor 8.4.3 وتطابق مرجع Swift؛ لا يعود اعتماد core
  غير المباشر إلى 8.5.0 الذي كان في القفل البعيد.
- **LF-002 الأحدث يحل محل قرار العرض السابق:** حالة مكتمل لا تجعل checkpoint
  صفريًا أو مفقودًا مساويًا لإجمالي الكتالوج. المكتبة وقسم الفصول يعتمدان
  التقدم المحفوظ نفسه. لا اختلاق لتاريخ القراءة. راجع [[12-Device-Repairs]].
- تبقى نبذات الأعمال الستة وروابط الناشرين وتنوع المؤلفين محفوظة مع تصميم
  الاستكشاف والبروفايل الأحدث. لا تدمج هويات أعمال بناءً على العنوان.
- جرى ربط جذر التطبيق نفسه بتاريخ Git وفرع عمل محلي يتتبع `origin/main`،
  مع إبقاء الدمج المحلي قابلًا للمراجعة؛ لا دفع GitHub أو إصدار جديد.

## حدود التحقق

نجح تشغيل المجموعة الكاملة الحالية: **1168 اختبارًا، صفر فشل**. ونجحت
اختبارات التوافق المستهدفة (43 حالة) وفحص البروفايل عبر أربع حالات لغة/تخطيط/
ثيم وعروض من 320 إلى 768، بلا أخطاء JavaScript. جرى التحقق من محتوى ملفات
JSON وCSV والتشخيص ومن بقاء رابط مصدر النبذة. اختبارات واجهة القوائم الأقدم
احتاجت تحديث السيناريو لخطوة اختيار نوع القائمة ولعرض المراجعات داخل تبويب
التغريدات؛ هذه تغييرات واجهة مقصودة في المصدر البعيد، وليست فقدًا للمحتوى.

أضيف توافق صغير لإخفاء اختصار `Reviews` بصيغة الجمع من شريط مقاييس القراءة،
مع اختبار يشغّل الدالة الفعلية. جرى تحديث ملفات الويب الأصلية المولدة ومراجع
Swift دون إنشاء IPA جديد. إيصال الجولة المحلي يحتفظ بتفاصيل كل فحص وحدوده.

الاختبارات ونتائج المتصفح الحالية تسجل بعد اكتمال الدمج؛ لا تُنقل أرقام
الجولة السابقة إلى هذه الجولة. الحزمة المحلية المرسلة سابقًا إلى Discord
تسبق هذا التحديث، وليست دليلًا على تحديث TestFlight أو الآيفون.

لا تُشغَّل migrations الجديدة أو الأدوات التاريخية تلقائيًا. لا تغيير في
الخدمات أو الأسرار أو الملكية. الشراء مؤجل بطلب المستخدم.

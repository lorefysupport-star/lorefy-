# جلب المصدر وتنظيم رواية المشروع

## الطلب والحدود

جلب آخر GitHub، تنظيم المشروع، والتحقق من حالته وتوفير رواية كاملة في
Obsidian. التطوير للمصدر فقط: لا build أو IPA أو Apple أو TestFlight، ولا
تغيير أسرار أو قاعدة بيانات. رفع إصلاحات المصدر منفردة يبقى مطلوبًا.

## المزامنة المحققة

- البداية `542b39c`، ثم `git fetch origin` كشف ثلاثة commits على main:
  `279a9dc` و`c727644` و`64e4e63`.
- حُفظ diff ثنائي ونسخة للملفين غير المتتبعين خارج المستودع، وأُنشئ stash
  استرجاع قبل `git merge --ff-only origin/main`. المزامنة وصلت `64e4e63`.
- أُعيد تطبيق المحلي مع إبقاء stash. اندمج تعديل نمو الشخصيات تلقائيًا.
  التعارضات اقتصرت على الفهارس المولدة وملفات manifest المشتقة.
- استُخدم manifest الأحدث لأن بيانات الكتالوج البعيدة تغيرت؛ النسخة المحلية
  القديمة تختلف في وصف حجم المصدر فقط. أعيد توليد فهارس المعرفة من المصدر
  المدمج. لم تُستبدل الملاحظات اليدوية أو إعدادات Build 35 السابقة.
- النسخة الاحتياطية المحلية تحت `artifacts/lorefy-sync-20261015-64e4e63/`
  في مجلد المحادثة، خارج التطبيق والخزنة وGit. لا تنشر تلقائيًا.

## معالجة ما كشفه الفحص

- التشغيل الأول للمجموعة: 1198 اختبارًا، 1197 نجاحًا وفشل واحد. اختبار
  الكاش كان يتوقع رابط growth القديم؛ حُدّث التوقع إلى الإصدار الفعلي دون
  إضعاف التحقق. نجحت 12 حالة موجهة، ورُفع التعديل منفصلًا في `57db5ed`.
- التشغيل التالي كشف عدم تطابق `sourceBytes` في نسخة manifest الأصلية
  داخل Xcode بعد توليد أصول الويب. عدد السجلات و`contentHash` لم يتغيرا.
  وُحّد وصف الحجم في المصدر ونسختيه؛ نجحت 14 حالة package، ورُفع `a76afff`.
- اختبار package يشغّل مولّد أصول الويب فقط؛ لا يبني أو يوقّع تطبيق iOS.
  لم يُشغّل `ios:sync` أو xtool أو EAS، ولم تُرفع أي نسخة إلى Apple.

## إيصال التحقق الحالي

بتاريخ 2026-10-15، على `a76afff` مع تعديلات التنظيم والذاكرة فقط، وبعد
إبقاء إعدادات Build 35 المحلية السابقة كما كانت:

- `npm test`: exit 0؛ 1198 اختبارًا ناجحًا، صفر فشل وإلغاء وتجاوز.
  السجل المحلي خارج Git: `artifacts/lorefy-sync-20261015-64e4e63/full-suite-verified.log`
  في مجلد المحادثة. يتضمن اختبار تطابق جميع أصول الويب المشحونة مع نسختيها.
- `npm run memory:refresh` ثم `npm run memory:audit`: exit 0؛ 59 ملاحظة،
  497 ملف مصدر مفهرس، بصمة حديثة، بلا روابط مفقودة أو ملاحظات يتيمة أو تكرار.
- `node --test tests/project-memory.test.js`: 17 اختبارًا ناجحًا.
- `git diff --check`: exit 0؛ لا أخطاء whitespace. تحذير LF/CRLF في Windows
  لا يعني تعديل بيانات الحساب أو إنشاء إصدار.
- `git ls-files -u`: فارغ؛ لا تعارضات دمج متبقية. نسخة الاسترجاع محفوظة.

هذه شهادة تحقق للمصدر في تلك اللحظة، لا للأجهزة أو الخدمات الحية.
بعد commits التوثيق تُحدّث البصمة المحلية مجددًا حتى تطابق HEAD الجديد.

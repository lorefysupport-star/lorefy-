# تسليم تحسينات السكيلز إلى GitHub

طلب المالك صراحة «إرفع إلى قيت هب». هذا إذن بنشر مجموعة التغييرات المحلية لهذه المحادثة على الريموت القائم، ويحدّث حد «محلي فقط» السابق فيما يخص GitHub. وجهة المستودع origin هي https://github.com/lorefysupport-star/lorefy-.git وفرع العمل main.

## المجموعة المسلّمة

- تحسين بحث الشخصيات: عزل المتصلين وحماية التخزين التالف، تبويبات الكيبورد، ورسائل بحث حسب الوضع وتعافيه.
- زر إيقاف/تشغيل واضح لعرض الاستكشاف مع احترام تقليل الحركة.
- أوصاف عربية أضيفت سابقًا من مصادر الناشر المراجعة، مع إبقاء بيانات المستخدم والأغلفة؛ هذه ليست أوصافًا جديدة في جولة الرفع.
- تحسين قراءة النبذة والتوسعة عند الحاجة، مع قرار المالك النهائي حذف رابط المصدر من العرض وإبقاء النبذات.
- Humanizer لرسالة المراجعات الفارغة؛ فلاتر القراء بحالة اختيار واضحة؛ إخفاء شريط البيانات الفارغ؛ تقديم أنظف لعنوان الفصل والاحتفاظ بالمعروف عند فشل الطلب.
- الاختبارات والتوثيق المتعلق بهذه المجموعة، وأصول الويب المولّدة المتتبعة المطابقة للمصدر.

## التحقق قبل الرفع

جُلب origin/main أولًا ولم توجد تغييرات أحدث من HEAD الأساسي90a392e. نجح فحص كامل جديد قبل الرفع:2348اختبارًا،0إخفاقات، في pre-push-tests.log داخل outputs/lorefy-hallmark-chapters في مجلد الشات. فُحصت قائمة الملفات والاختلافات، ولم تظهر قيم تشبه مفاتيح خاصة ضمن فحص الأنماط المحدد؛ ليس هذا اعتمادًا أمنيًا شاملًا. نتائج المتصفح مفصلة في الجلسات المرتبطة.

إثبات الرفع هو تطابق SHA المحلي وrefs/heads/main على origin بعد git push، ويُحفظ في receipt.json داخل outputs/lorefy-github-push بمجلد الشات. لا يُستنتج نجاح الشبكة من هذا التوثيق وحده.

لا بناء iOS أوEAS أوApple/TestFlight ضمن هذا الإذن. الجهاز وVoiceOver والخدمات الحية تبقى ضمن حدودها السابقة.

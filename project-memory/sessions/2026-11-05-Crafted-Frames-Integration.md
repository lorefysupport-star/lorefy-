# Eight approved crafted collections

The owner approved four object, two expressive elf and two crochet frames and
requested actual app integration. This supersedes their standalone-study
boundary only, not the older local-only elf/atelier packs.

[Integration scope](../../docs/CRAFTED_FRAMES_INTEGRATION_2026-11-05.md) maps the
strict catalog and four `lorefy-crafted-*` modules to existing shop, profile
geometry and scheduler contracts. Articulated ears, cloth, flowers, hook/yarn and
other objects keep independent movement. Prior media, layouts, catalogs and
billing gates survive. Atlases are about 85 percent smaller without resizing.

Fresh full suite: 3416 passed. Browser: 720 profile checks across 96 owner cases
and 24 visitor fixtures, plus 31 actual store/pixel checks. The latter includes
all eight preview/apply commands and 32-pose aperture/edge tests per frame.
Raw screenshots and evidence stay outside the vault and app bundles.

After explicit approval and twelve isolated PostgreSQL tests, the eight free
frame/page IDs were enabled through Supabase SQL Editor. Read-only verification
confirmed auth/owner/private/block checks and grants unchanged. No user rows or
migration-history entries changed. See the integration report and local SQL.

Runtime assets selectively mirrored; no native build, Apple upload or GitHub
push. Physical-device and live two-account UI validation remain pending. An
older installed client does not automatically gain the new renderer modules.

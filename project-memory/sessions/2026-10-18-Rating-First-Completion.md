# نشر تقييم العمل غير المسجل يضيفه للمكتملة

المصدر الأب `49a38df`. طلب المالك الحالي يحدّث سياسة LF-028 للنشر الحالي
فقط: تقييم عمل غير مسجل يضيفه للمكتملة. بقي منع التهيئة من مراجعات قديمة،
وحماية الحالة والتقدم في LF-024، واستقلال حذف المراجعة عن المكتبة كما هي.

`lorefyReviewCompletionAllowed` يفحص وجود المفاتيح لا قيمتها: أي حالة مكتبة
أو checkpoint أو علامة إزالة تمنع الإضافة، حتى الصفر. App يحدث snapshot
قراءة المحرر في كل render. يلتقط `tr` الأهلية عند البداية ويعيد فحصها بعد
نجاح الطلب وحراس الحساب والمحرر، ثم يستخدم `Zn` الحالي لحفظ إجماليات مرة
واحدة. لا تغيير للصيغ أو مفاتيح التخزين أو إنشاء تاريخ جلسة قراءة وهمي.
اسم الزر: «نشر وإضافة للمكتملة» / `Publish and mark completed`؛ وإلا نشر فقط.

15 حالة في `tests/review-first-completion.test.js` تختبر النشر الأول والصفحات
والحالات الخمس والصفر والإزالة والفشل وتغير الاختيار/الحساب أثناء الطلب،
وإعادة النشر ونمو الكتالوج وعدم backfill وتحديث snapshot الفعلي. حالة
إضافية في `tests/review-editor.test.js` لاسم الزر باللغتين. خمس حالات فشلت
قبل الإصلاح؛ مجموعة المراجعات نجحت 70/70.

المجموعة الكاملة الأولى: 2106 نجاح وفشل واحد بمقارنة ملخص الكتالوج بسبب
CRLF على Windows. فحص مستقل: rawEqual=false وnormalizedEqual=true؛
2993 بايت مقابل 2991، والفارق نهايتا سطر فقط. طُبّعت CRLF داخل مقارنة
الاختبار فقط؛ بقيت تأكيدات metadata والحجم وحذف workParts. لم يُعد كتابة
الكتالوج. المجموعة المركزة أصبحت 85/85؛ التحقق النهائي `npm test`:
**2107/2107، صفر فشل، exit 0**، مدة 67864.7015ms.

في ديمو 8795 أُعيد نشر نفس تقييم Berserk ‏4/5 دون تغيير الدرجة أو إضافة نص.
أصبح التقدم 384/384 وظهر في المكتبة مع Hunter x Hunter. الإحصاءات أصبحت
2 مكتملة و804 فصول و161 ساعة تقديرية. أُعيد النشر مرة أخرى ثم حُمّل
البروفايل مجددًا؛ بقيت القيم ثابتة. صورة `rating-completion-after-reload.png`
و`rating-completion-tests.tap` خارج Git والخزنة بمجلد أدلة معاينة 18 أكتوبر.

الحالات المتأخرة والفشل اختبارات مصدر حتمية؛ لا شهادة جهاز أو خدمة حية.
استُخدمت metadata Berserk الحالية 384 كما هي؛ حداثتها وحالتها الخارجية لم
تراجعا. المراجعات التاريخية الأخرى لم تتحول تلقائيًا لمكتملة.
